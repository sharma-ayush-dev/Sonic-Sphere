# SonicSphere

SonicSphere is a sleek, modern landing page concept for a music streaming or discovery platform. It features a stunning dark mode aesthetic, vibrant neon gradients, and premium glassmorphic UI elements.

## Features

- **3D Spline Integration**: A dedicated, fully responsive container displaying interactive 3D WebGL scenes natively through Spline.
- **Glassmorphic UI**: Beautiful, frosted-glass navigation bars and footers achieved using CSS `backdrop-filter`.
- **Dynamic Animations**: Smooth, staggered entrance animations (fade-in & slide-down) that trigger on page load, elevating the overall premium feel.
- **Responsive Layout**: Adapts a side-by-side split screen on desktop into a stacked, mobile-friendly design.
- **CSS Variables & Theming**: Easily customizable color palettes using centralized CSS custom properties.

## Tech Stack

This project is built purely with Frontend fundamentals to be lightweight and fast:
- HTML5
- CSS3 (Vanilla)
- JavaScript (Vanilla)

## Setup & Preview

To view the landing page locally:
1. Clone the repository.
2. Open `index.html` in any modern web browser.
3. No build steps or dev servers are required!
